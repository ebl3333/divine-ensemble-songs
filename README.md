## Prompts for every song

- [`prompts/cinematic-prompt-director.txt`](prompts/cinematic-prompt-director.txt) — paste into ChatGPT first; it turns any scene idea or reference picture into 4 cinematic shots (wide, human height, close, drone).

## Inside each song folder

- `README.md` — the song, its characters and which scene goes with which lyric
- `SHOT-LIST.md` — line-by-line shots: time, lyric, scene, camera, how each shot ends, mood
- `references/` — locked characters, so faces and costumes stay the same in every shot
- `stills/` — one starting picture per scene; `stills/spares/` holds earlier versions
- `prompts/` — the ChatGPT prompts used for that song
- `clips/` — the moving clips made from the stills; `clips/tests/` for tests
- `final/` — lyric timing and the finished music video
- `plans/` — older plans kept for reference
