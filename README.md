# Divine Ensemble — Songs

Music videos for Divine Ensemble (Dazadi Foundation). One folder per song.

| Song | Album | Status |
| --- | --- | --- |
| [God Is About to Show Up](god-is-about-to-show-up/) | God Is About to Show Up | Stills done, clips in progress |
| [Deliverance: Shackles to Freedom](deliverance-shackles-to-freedom/) | Deliverance: Shackles to Freedom | Not started |
| [I Am](i-am/) | I Am | Not started |

## Inside each song folder

- `references/` — locked characters (R1, R2 …), so faces and costumes stay the same in every shot
- `stills/` — one picture per scene, named by shot number (A2, B1, C1 …); `stills/spares/` holds alternates
- `clips/` — each still animated into a moving clip, same names
- `final/` — the finished music video
